# Jin Young Oh — Portfolio

Static personal portfolio for https://joh748.github.io/.

The site presents MinglePlay, ForkFolio and the local AI Orchestration project, with direct links to the existing public demos. Source repositories for those projects remain private. Orca and Chorus are credited as external workflow tools.

## Edit

- `index.html`: biography, project case studies, experience and links.
- `styles.css`: responsive layout and visual style.
- `script.js`: accessible project filtering.
- `assets/`: screenshots of the public project interfaces and cover artwork.

No install or build is required. Serve this directory with any static HTTP server. GitHub Pages publishes the root of the `main` branch; `.nojekyll` bypasses Jekyll.

Project information and screenshots were reviewed on 1 November 2026. Pilot status and limitations should be updated as the projects develop. The case studies describe AI-assisted personal development, not unaided authorship or measured commercial outcomes.
