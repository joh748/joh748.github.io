ForkFolio

Food discovery for Auckland.

Role
Personal project · AI-assisted development
Status
Auckland pilot
Technology
React, TypeScript, Vinext, Cloudflare Workers, D1

Overview

ForkFolio is a food-discovery PWA that combines a map, food preferences and restaurant information. The Auckland pilot explores how to make local discovery useful while showing only information supported by its sources.

My contribution

I’m developing the product with AI coding assistants, working across the interface, discovery data and deployment workflow. The current focus is source-aware information, offline read recovery and clear boundaries between public and authenticated features.

Engineering decisions

  • Keep unknown information absent. Prices, opening hours and menus stay absent when there is no supporting evidence.
  • Use a discovery projection. Versioned API routes serve a D1 discovery projection, with Drizzle defining the data model and a separate ingestion worker supporting updates.
  • Separate access boundaries. The React/Vinext application uses AWS Cognito for authenticated areas and Cloudflare Workers for its runtime.

Evidence and status

The public pilot is evolving. Menu coverage and data quality remain development priorities. Virtual credits have no cash value; the app does not take payments or orders.
