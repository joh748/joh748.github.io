Overview

FinTrack is a financial-tracking application developed by a University of Auckland SOFTENG 310 team in 2024. It combines a React interface, an Express backend and PostgreSQL for income and expense tracking.

My contribution

My contributions included Gemini API feature integration, controller and response-parsing tests, form behaviour and loading-state improvements, and setup documentation. The application belongs to the full project team; the commit history identifies my specific changes.

Engineering decisions

  • Connect the feature across layers. The integration links React inputs to Express routes and formats generated responses for display.
  • Test the boundary. Chai assertions and Sinon stubs exercise the controller and response cleaner.
  • Handle requests in the interface. Form submission prevents a page reload and disables the request button while loading.
