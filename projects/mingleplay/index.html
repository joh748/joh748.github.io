MinglePlay

Phone-first multiplayer icebreakers.

Role
Personal project · AI-assisted development
Status
Community beta
Technology
React, TypeScript, ASP.NET Core, SignalR, PostgreSQL

Overview

MinglePlay brings a group into a shared game room. A host starts the session and players join from their phones without creating accounts. The project explores real-time interaction on mobile networks.

My contribution

I’m developing this personal project with AI coding assistants. The work focuses on the host and player experience, authoritative room state and recovery when connections fail. I use scoped changes, review and verification as part of development.

Engineering decisions

  • Keep rules on the server. The server controls game state and the information each player can see. SignalR notifies clients when something changes.
  • Make retries safe. Commands carry an ID. An exact duplicate uses its existing command receipt instead of applying the action twice.
  • Persist room state. PostgreSQL stores room state and command receipts to support recovery.

Evidence and status

The public beta supports one hosted room with up to 30 players. Newer modes still need real-device and group-pilot checks. Free hosting means the backend may take time to wake.
